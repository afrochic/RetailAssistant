# ADR 0003: Client X naming and public submission cleanup

The user requires the client's identity to be removed and the report to be exactly one page. Current public source uses Client X and CX references. Outbound retailer links and identifying screenshots/raw audit payloads are withdrawn rather than relabelled as original evidence. The private source is unchanged; approved product fields form a distributable Client X source with explicit redaction metadata, from which preprocessing and TF-IDF can be reproduced. Loader integrity checks remain mandatory. Null product URLs are accepted only for a manifest explicitly declaring retailer-link redaction. Optional external URLs require a private runtime host allowlist; no client domain is hardcoded.

Historical experiments move to legacy/flipkart; current setup/docs point to the two app roots and canonical root Compose. AI_USE.md must preserve the student's exact replacement. Original evidence is privately archived outside the repository. New measurements are separated from historical release evidence. No history rewrite, main merge or production change is part of this cleanup. Previously published commits/deployments may retain identifying text; this is current-snapshot client-name redaction, not a claim of irreversible de-identification.
