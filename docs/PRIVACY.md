# Client-name redaction and scope

Client X is the public pseudonym. The current submission removes the client's name/domain from source, metadata, distributable data and academic text. Public product URLs are null; citations retain product IDs under CX. Original screenshots and raw historical audit dumps that exposed identifying details were withdrawn from the current tree, not edited and represented as original captures. Original source and evidence are privately preserved outside this repository.

The export utility accepts private aliases at execution time; no actual alias is hardcoded. The included distribution source can be ingested/refitted without accessing private files. Any new approved source must be reviewed and passed through appropriate alias/URL redaction before public release. A private runtime host allowlist is required before any future retailer links can be served; its default is empty.

This cleanup does not rewrite prior Git commits, erase old GitHub Actions logs or modify the previously deployed application. Those existing external/historical copies may retain identifying information. A history purge or production update requires separate explicit authorization and validation. Product text/IDs can also be externally reidentified; the transformation is client-name redaction rather than proof of full dataset de-identification.
